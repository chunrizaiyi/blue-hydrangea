## 一、执行范围

本阶段计划检查系统通知、息屏计时、到点提醒、耳机路由、白噪音长时间循环及小米设备兼容性。本次实际完成的是模拟器上的倒计时息屏到点和系统通知暂停、继续两项。真机相关项目保留为待执行，不用模拟器结果替代。

Android 测试包在 Debug 构建时通过环境变量启用独立包名和“测试”名称。未启用该变量时，正式包名与应用名称仍按原配置生成。隔离方式见 [构建配置](../../android/app/build.gradle.kts) 和 [应用清单](../../android/app/src/main/AndroidManifest.xml)。

## 三、执行过程中的问题

1. 首次隔离包构建等待在线依赖下载，未完成。改为使用已缓存的 Android x64 依赖进行模拟器专用构建，构建成功。该构建只用于本次模拟器测试，不能作为面向真实手机的通用安装包。
2. C-05 首轮脚本在创建会话前读取权限字段；原生接口此时返回空状态，因而脚本断言失败，未进入计时。脚本改为先检查权限接口、启动会话后再读状态，复测通过。
3. C-07 前两轮自动等待没有收到“暂停”状态，现场核对发现通知虽已创建，但测试人员未按到通知按钮。延长操作窗口并在通知界面实际按下“暂停／继续”后，状态断言通过。前两轮不计作产品失败，也不计作通过。

本次执行未确认产品缺陷。构建等待和脚本失误按原经过记录，不计入产品缺陷数。
