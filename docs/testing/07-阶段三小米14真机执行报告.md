## 二、执行方法

1. 使用 Flutter 集成测试在真实设备中驱动页面、读取实际 SQLite 数据、调用 Android 原生接口。
2. 每次执行记录设备型号、系统构建号、源码基线、起止时间及退出码，保留失败与复测日志。
3. 数据测试首先检查应用私有目录中的包名。只有确认属于 `.stage3test` 后，才创建或清理虚构测试数据。
